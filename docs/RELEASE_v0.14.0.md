# Lanterns of the Lost Dream v0.14.0

Release date: 2026-10-17.

- Four saved chapters with the current map edits and automatic black-fade transitions.
- Griffy/Averia storybook typography and a dismissible opening explanation in chapter one.
- Six original gentle, ethereal arrangements: separate exploration themes, two Boss stages and a warm victory theme.
- Fitted physical collision on substantial scenery, with old hidden tree collision removed.
- The R key no longer restarts the chapter; its HUD/control-table hint is removed. Defeat-screen retry remains.
- Floating candy color labels are reserved for the Boss chapter. Chapter three retains colored candy, pickup/swap actions and potion recipe prompts.

The local macOS arm64 export is `Builds/macOS/Lanterns of the Lost Dream.app`;
the archive is `Builds/Lanterns-of-the-Lost-Dream-v0.14.0-macOS-arm64.zip`.
Builds are excluded from Git. Source and related resource/QA changes are synchronized
to the existing GitHub repository; unrelated in-progress GDD revisions remain local.

Mixamo and Poly Halloween source assets remain excluded from the public repository;
their credited artwork is included in the compiled game. Restore those assets before
building a fresh source clone. Font and instrument-bank notices accompany source.

Release validation and package hashes are recorded under `docs/qa/v0.14.0`.
Automated verification does not substitute for independent human playtesting.
