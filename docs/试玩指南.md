# 梦境南瓜灯：原型试玩指南

双击 `Builds/macOS/Lanterns of the Lost Dream.app` 启动。主菜单按 Enter 从第一关开始，也可以点选任意一关测试。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标 |
| 旋转镜头 | 按住中键拖动 / Alt＋鼠标左键拖动 |
| 镜头缩放 | 滚轮 |
| 恢复默认镜头 | F |
| 弓箭射击 | 按住鼠标左键 |
| 点灯 / 拾取或交换糖果 | 靠近后按 E |
| 扔出糖果 | 鼠标右键 / Q |
| 跳跃 | 空格（落地后可再次跳跃） |
| 冲刺闪避 | Shift |
| 暂停 / 继续 | Esc |
| 重试本关 | R |
| 静音 | M |

**第一关：** 用弓箭打碎金色练习方块，沿路点亮两盏南瓜灯。第一盏灯会显现两座圆形跳台，按空格跳跃、用方向键调整落点，落在发光圆圈内，到对岸后再探索下一盏灯。第二段保留桥，点灯会驱散黑雾并保存复活点。消灭小飞龙后，在最后一座岛拾取粉色糖果，砸碎粉色封印。全部目标完成后，走进发光拱门，按 Enter 进入下一关。封印打破前，最后区域每 3 秒补齐两个刷新点上的糖果，每处最多一颗。即使手里有糖果或之前全部扔空，地上也会补充；暂停时计时停止。

**第二关：** 道路开始转弯，需要探索三盏灯的位置，并消灭五个飞行敌人。保留基础小飞龙和进化飞龙，另外加入蓝色幽灵（慢速光球）、蜂怪（三发扇形弹幕）和小恶魔（沿预警路线俯冲）。幽灵的光球需要持续移动避开；蜂怪弹幕可以找空隙或用 Shift 闪避；小恶魔会先在地面标出路线，向侧面离开即可。所有敌人都用弓箭攻击，全部清除后才能打开出口。最后一盏灯会显现三座较小的圆形跳台，路线左右错开，中间一座较高，需要依次跳到出口岛。飞龙攻击前会发光提示；移动或按 Shift 冲刺避开火球。点灯可以恢复一点生命，掉下岛会扣一点生命并返回最近的灯。

**第三关：** 先点亮入口的灯，通过两座更小、有高低差的圆形跳台进入古堡。地上的橙色圆圈是炸弹范围，及时离开。靠近糖果按 E 拾取，一次只能携带一颗。先看 Boss 血条下方的 MATCH 提示，选择与它身体颜色一致的糖果。等界面显示 SHELL OPEN 或 STUNNED，再瞄准它扔糖果；平时外壳会挡住攻击。命中六次即可胜利。

血量降至一半（3/6）时，南瓜头会首次冲撞，之后每轮炸弹结束还会再次冲撞。地面先标出路线，预警持续 1.6 秒，随后它沿锁定方向冲过去。向路线侧面移动或按 Shift 闪避；跳跃不能直接越过巨大的南瓜头。冲撞结束后，它会停顿并转向玩家，对应颜色的弱点开放 2.4 秒，此时可以扔糖果反击。命中一次或窗口结束后，它收起弱点返回原位。后半程每轮炸弹数量也会增加。

v0.9 加入颜色匹配：第一轮只有粉色；首次有效命中后引入蓝色，第二次有效命中后引入金色。粉色 [O]、蓝色 [<>]、金色 [*] 同时用文字、符号和颜色标识。每轮攻击到反击窗口结束都保持同色，之后才可能换色。错色糖果会被消耗，但不会扣血，也不会提前关闭反击窗口。拿错时，靠近另一种颜色的糖果按 E，可以直接交换，原来手中的糖果会留在地上。每次补充时，会在 Boss 身体范围外保留至少两颗当前需要的糖果；手中和飞行中的糖果不会被自动改色。

半血冲撞保留。第一关和第三关的保存地图保持不变；第二关只替换三个敌人的模型和种类，岛屿、桥梁、跳台、灯、敌人位置和数量保持原样。

当前版本使用角色身后的第三人称透视镜头，降低高度并拉近 Timmy，移动时平滑跟随。镜头可以旋转和缩放，遇到有实体碰撞的墙或树干会自动靠近以避免穿墙；Boss 战会适当拉远并朝向南瓜头。手动旋转可以暂时覆盖 Boss 镜头的自动朝向，F 恢复默认。Alt＋左键拖动镜头时不会射箭。

v0.7 在三关各加入一段圆形跳台连接，其余区域保留原有布局。平台在点灯后出现，失足仍返回最近的灯。跳台边缘的青色光圈和金色中心用于判断落点。

v0.6 将空格改为单次跳跃，加入起跳屈膝、腾空收腿、下降和落地缓冲动作；原来的闪避改为 Shift。空中可以移动、射箭和扔糖果，跳跃本身不提供无敌。跳跃高度默认 2.2，可在玩家 PlayerMotor 的 Jump Height 字段中调整。地图场景保留原有布局。

v0.5 修正了射箭姿势：左手在角色正前方持弓，右手在脸侧拉弦，箭从弓的位置沿瞄准方向飞出。

主角使用 Mixamo 的 Timmy（红帽子、绿外套），接入待机、跑步、弓箭瞄准和投掷动画；弓和糖果跟随手部骨骼。小飞龙使用 Quaternius Ultimate Monsters 素材包中的 Dragon、Dragon_Evolved、Ghost、Armabee 和 Demon 模型，以及素材自带的飞行、攻击和死亡动画。南瓜 Boss 和场景仍采用原创几何模型。游戏界面为英文；难度和镜头可以根据你的试玩继续调整。

源码保存在当前 Unity 项目中，v0.9 源码快照用于同步到 [GitHub 仓库](https://github.com/RcO2Rob/halloween-dream-adventure)。当前本机项目可直接用 Unity 6000.6.2f1 打开，载入 `Assets/Scenes/01_FirstLight.unity` 即可继续编辑。公开仓库不包含 Mixamo 原始模型、动画和贴图，新克隆项目需要先按 [素材恢复指南](MIXAMO_SETUP.md) 补齐；本机素材和试玩包均保留。

在 Unity 的 Hierarchy 中搜索 `Jump platform`，选择对应的平台根对象调整位置与缩放，碰撞和发光边缘会一起改变。入口、出口标记应放在岛的安全地面上。原来的三张地图已备份到 `docs/map-backups/v0.6.1`，本次只替换了指定连接段。

如果移动了某座跳台，也请对齐同一段路径下 `Faint round platform silhouettes` 中对应的未点亮轮廓，保持点灯前后的提示位置一致。
