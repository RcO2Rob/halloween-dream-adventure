## 剩余重叠的判断

人工语义复核未发现仍需大段删减的重复解释。几处必要的重叠予以保留：

1. 教学表与关卡都提及同一能力：前者比较学会与复用，后者描述实际关卡流程。
2. Main Rules 与 FSM 都涉及换糖、掉落、受击和 Boss 开壳：规则说明动作结果，FSM 明确触发条件与下一状态。
3. 糖果供应同时出现于规则与 Cybernetic Systems：前者规定供给，后者解释该实例为何构成负反馈控制。
4. Emergent Systems、Uncertainty 与 Conflict 使用部分相同机制，但分别分析战术组合、结果变化和目标对抗，不重复讲完整玩法。

辅助文本检查未发现完全相同的叙述段落，也未发现不同 section 的叙述段落包含相同的连续 12 词序列。该检查排除表格，仅用于发现字面复述；上述语义审查负责判断换词后的重复。
